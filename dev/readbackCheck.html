Readback check

The GPU renderer copies each frame's escape counts back without waiting: readPixels into a pixel pack buffer, a fence, and getBufferSubData once the fence says the GPU is done. Chrome (152) warns about every such read, "READ-usage buffer was written, then fenced, but written again before being read back", which means it read the buffer the slow way, not from the copy it made ahead of time.

This page does just that, in each of the ways that might matter, five times each, so open the console to see whether a version of the browser still warns. In Chrome 152 every one does, so it isn't anything the renderer does; the counts are small (a few hundred kilobytes), and reading them the slow way costs well under a millisecond.
