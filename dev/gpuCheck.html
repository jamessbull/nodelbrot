GPU check

Renders each view with the GPU and the CPU renderers to the same depth and compares their escape counts, pixel by pixel. The GPU has only 32-bit floats, which comes to sampling each pixel a few hundred-thousandths of a pixel away. On the boundary, where escape counts vary on scales far finer than a pixel, that is enough to change a few percent of them, as much as moving the pixels that far in double precision does. They pass with at least 93% within 1%.
